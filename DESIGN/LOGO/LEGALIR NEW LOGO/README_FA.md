# هویت پیشنهادی تازه لیگالیر

نام انگلیسی: LEGALIR

نام فارسی: لیــــــــگالـیــــر

مفهوم نشان، کتاب قانون در قالب سپر محافظ است. دو صفحه و جلد آن یک ساختار واحد، متقارن و روشن می‌سازند. کتاب به دانش و راهنمایی حقوقی و سپر به امنیت و حفاظت اشاره دارد. طراحی ساده و بدون جزئیات تزئینی برای نمایش در اندازه‌های مختلف آماده شده است.

رنگ نشان و تایپوگرافی: #D29A0D، از خانواده طلایی لوگوی اصلی.

تمام فایل‌های اصلی PNG و SVG پس‌زمینه و فضاهای داخلی شفاف دارند. پس‌زمینه روشن و تیره فقط برای preview است.

## فایل‌ها

- legalir-logo-bilingual.svg / .png: لوگوی کامل عمودی با هر دو زبان.
- legalir-logo-horizontal.svg / .png: ترکیب افقی برای هدر و کاربردهای کم‌ارتفاع.
- legalir-symbol.svg / .png: نشان مستقل، مناسب آیکون و ناوبار موبایل.
- legalir-wordmark-en.svg / .png: تایپوگرافی انگلیسی مستقل.
- legalir-wordmark-fa.svg / .png: تایپوگرافی فارسی مستقل.
- favicon.ico: نسخه چنداندازه‌ای 16، 24، 32، 48، 64، 128 و 256 پیکسل.
- preview.png: پیش‌نمایش کاربرد روی زمینه روشن و تیره؛ فایل لوگوی شفاف نیست.

متن‌ها در SVG به مسیر برداری تبدیل شده‌اند تا نمایش به نصب فونت روی دستگاه مقصد وابسته نباشد. تایپوگرافی انگلیسی بر پایه URW Gothic Demi و فارسی بر پایه Noto Kufi Arabic Bold با کشیده‌های درخواست‌شده تنظیم شده است.

برای آیکون‌های کوچک، از نشان مستقل استفاده کنید. فایل را بدون تغییر نسبت ابعاد نمایش دهید.
